# AI Lead Generation Widget

A frontend capstone project for generating and collecting leads through an AI-powered widget.

## Project Overview

The AI Lead Generation Widget is designed to help businesses collect potential customer information through an interactive frontend experience.

The project will focus on building a simple, accessible, and responsive user interface.

## Planned Features

- Lead generation form
- User-friendly interface
- Responsive design
- Form validation
- Accessible UI components
- AI-assisted development workflow

## Technology Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub
- AI coding assistant

## Development

This project is being developed as part of the FlyRank frontend capstone.
