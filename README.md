# AI Lead Generation Widget

A frontend capstone project for generating and collecting leads through an AI-powered widget.

## Project Overview

The AI Lead Generation Widget is designed to help businesses collect potential customer information through an interactive frontend experience.

The project will focus on building a simple, accessible, and responsive user interface.

## Usage

### Settings Form

The project includes a comprehensive settings form for configuring the AI Lead Generation Widget. The form features:

- **Real-time validation** with immediate visual feedback
- **Character counting** for fields with limits
- **Responsive design** for all device sizes
- **Dark mode support** for user comfort
- **Persistent storage** using browser localStorage
- **Accessibility** features for inclusive user experience

To access the settings form:

```bash
# Open settings.html in your web browser
# File path: fe-capstone/settings.html
```

For detailed information about the settings form, see [SETTINGS_FORM.md](SETTINGS_FORM.md).

### Testing the Form

To test the validation:

1. Open `settings.html` in your browser
2. Try submitting the form without filling required fields
3. Observe real-time validation messages
4. Fill in all required fields with valid data
5. Click "Save Settings" to persist data to localStorage
6. Refresh the page to verify settings are loaded

See [FORM_TESTING.md](FORM_TESTING.md) for comprehensive testing scenarios.
