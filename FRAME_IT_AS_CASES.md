# Case Study 1 — AI Lead Generation Widget

## The Problem

Manual lead generation can be time-consuming. I wanted to create a simple AI-powered widget that could interact with users, collect useful information from potential customers, and make the lead-generation process easier.

## What I Did

I built an AI Lead Generation Widget with a simple interface for collecting lead information. I kept the form focused by requesting only the necessary details and added validation for required fields and email input. Optional fields could remain empty when they were not needed.
I also added automated tests using Node's built-in test runner. The tests covered required fields, invalid email addresses, optional fields, and valid submissions. I kept the testing setup lightweight and reviewed the AI-generated changes carefully. During development, the AI created unnecessary documentation changes and initially suggested modifying `package.json` for testing, which I rejected because the existing setup was sufficient.
## What Came of It

The final widget had a clear interface and focused form behavior. All four automated tests passed successfully, covering the main validation and submission cases.

The project taught me that working with AI is not just about generating code. I learned to give AI clear requirements, set boundaries, review its changes, and verify the result with tests. I also learned more about validation, accessibility, edge cases, and keeping frontend features simple and maintainable.
