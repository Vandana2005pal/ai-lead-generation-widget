# AI Lead Generation Widget - AI Development Rules

## Project Overview

This project is a frontend capstone project for an AI Lead Generation Widget.

The goal is to create a simple, responsive, accessible, and user-friendly interface for collecting potential customer leads.

## Technology Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub

AI coding assistants may be used to support development.

## Coding Guidelines

- Write clean and readable code.
- Keep the implementation simple and maintainable.
- Use meaningful variable and function names.
- Avoid unnecessary complexity.
- Keep HTML semantic and accessible.
- Keep CSS organized and responsive.
- Use modern JavaScript where appropriate.
- Validate user input in forms.
- Do not expose secrets, API keys, or credentials in source code.

## UI Guidelines

- The interface should be responsive on desktop and mobile.
- Use clear labels for form fields.
- Maintain good keyboard accessibility.
- Provide clear feedback for user actions.
- Keep the user experience simple and intuitive.

## Git Guidelines

Use Conventional Commits.

Examples:

- feat: add lead generation form
- fix: correct form validation
- docs: update README
- chore: update project configuration

## AI Assistant Guidelines

When modifying the project:

1. Understand the existing code before making changes.
2. Make focused changes related to the requested task.
3. Do not unnecessarily rewrite unrelated files.
4. Explain important changes when appropriate.
5. Do not add dependencies unless they are necessary.
6. Never commit secrets or credentials.

## Project Status

The project is currently in the initial environment and repository setup phase.
## Development Workflow

Before making changes:

1. Understand the existing project structure.
2. Make small and focused changes.
3. Test changes when applicable.
4. Keep documentation updated.
5. Use clear Conventional Commit messages.
